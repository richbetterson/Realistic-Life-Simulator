Realistic Life Simulator - data files / файлы данных

These files are created automatically on first run if they are missing, and can be edited
while the game is closed. The copies here are the defaults.
Эти файлы создаются автоматически при первом запуске, если их нет. Их можно редактировать,
когда игра закрыта. Здесь лежат значения по умолчанию.

LifeHubs.ini        Life Hub marker locations / точки центра управления
GasStations.ini     Gas stations (fuel system) / АЗС
SpeedLimits.ini     Speed-limit overrides by street or zone / ограничения скорости по улицам и районам
Properties.ini      Homes, apartments and garages for sale / недвижимость и гаражи
VehicleCatalog.ini  Dealership catalogue / каталог автосалона
Shops.ini           Dealership and repair-shop locations / автосалон и автосервисы
